# ShadowDrive Tutorial Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 플레이어가 핵심 메커닉(그림자=도로, 물체 회전/이동, 낙하 출발, **천장=머리 막힘 장애물**, 등반 한계, 끼임)을 레벨 안에서 단계적으로 학습하도록, 데이터 주도 튜토리얼 콜아웃(callout) 시스템을 추가한다.

**Architecture:** 엔진은 이미 데이터 주도(레벨 JSON) + `GameStateMachine` + `Renderer` + `main.js` 오케스트레이션이다. 같은 결을 따라 (1) 레벨 JSON에 선택적 `tutorial.steps` 필드를 더하고, (2) 순수 로직 `TutorialController`(코어, 단위테스트)가 스텝 진행 상태머신을 담당하며, (3) `Renderer`/DOM이 현재 스텝 텍스트 박스 + 하이라이트(대상 메시 펄스)를 그리고, (4) `main.js`/`InteractionController`가 사용자 액션(회전/이동/Go/Next)을 컨트롤러에 이벤트로 흘려보낸다. **레벨 순서·개수는 바꾸지 않는다**(콜아웃만 부착).

**Tech Stack:** ES Modules + importmap, Three.js r159 (vendored), `node --test`, 번들러 없음.

이 플랜은 아래 기본값으로 작성됨. 다르면 실행 전에 알려주세요 — 해당 태스크만 조정.

1. **방식: 콜아웃 오버레이(기본)** vs 전용 튜토리얼 레벨 신설.
   - 기본값: 기존 레벨(L1, L5)에 콜아웃을 부착. 레벨 신설/재정렬 없음(가장 작은 변경).
2. **가르칠 위치:**
   - L1 → 그림자=도로 / 물체 회전·이동 / 낙하 출발 (기본 3스텝).
   - L5 → **천장=머리 막힘, 밑으로 통과** (사용자가 놓친 메커닉). 1~2스텝.
   - (등반 한계·끼임은 후속. 이번 범위 제외.)
3. **진행 트리거:** 각 스텝은 `advanceOn` ∈ `{next, rotate, move, go}`. `next`는 "다음" 버튼, 나머지는 해당 사용자 액션 감지 시 자동 진행. 기본은 대부분 `next`(읽고 넘기기) + 마지막 "Go 하면 출발" 스텝은 `go`.
4. **노출 시점:** PLAN 단계에서만. 레벨 진입 시 step 0부터, 완료(done)되면 오버레이 숨김. 한 번 본 레벨은 다시 안 띄움(localStorage 플래그) — *기본 OFF(매번 표시), 원하면 켬*.

// src/core/TutorialController.js
// 레벨 튜토리얼 스텝의 진행 상태머신. 렌더/입력 무관 순수 로직.
export class TutorialController {
  constructor(steps) {
    this.steps = Array.isArray(steps) ? steps : [];
    this.index = 0;
  }
  get done() { return this.index >= this.steps.length; }
  get current() { return this.done ? null : this.steps[this.index]; }
  /** eventType이 현재 스텝의 advanceOn(기본 'next')과 같거나 'force'면 다음으로. */
  advance(eventType) {
    const cur = this.current;
    if (!cur) return null;
    const need = cur.advanceOn || 'next';
    if (eventType === 'force' || eventType === need) this.index += 1;
    return this.current;
  }
  reset() { this.index = 0; }
}
```

// 현재 튜토리얼 스텝 표시. step=null이면 숨김. onNext=다음 버튼 콜백.
showTutorialStep(step, onNext) {
  const box = document.getElementById('tutorial');
  const txt = document.getElementById('tutorialText');
  const btn = document.getElementById('tutorialNext');
  this._tutorialHighlight = step ? step.highlight || null : null;
  if (!step) { if (box) box.style.display = 'none'; return; }
  if (txt) txt.textContent = step.text;
  if (btn) {
    btn.style.display = (step.advanceOn && step.advanceOn !== 'next') ? 'none' : 'inline-block';
    btn.onclick = () => onNext && onNext();
  }
  if (box) box.style.display = 'block';
}

// 하이라이트 대상 메시를 시간에 따라 emissive 펄스. render 루프에서 매 프레임 호출.
_pulseHighlight(tSec) {
  const tgt = this._tutorialHighlight;
  if (!tgt) return;
  const k = 0.5 + 0.5 * Math.sin(tSec * 4);     // 0..1
  let mesh = null;
  if (tgt === 'occluder0' || tgt === 'occluder1') {
    const idx = tgt === 'occluder0' ? 0 : 1;
    this.occluderGroup.children.forEach((m) => {
      if (m.userData.part && m.userData.part.movable && m.userData.part.index === idx) mesh = m;
    });
  }
  // start/goal/ceiling 하이라이트는 padGroup 마커 펄스로 확장 가능(후속).
  if (mesh && mesh.material && mesh.material.emissive) {
    const hov = mesh.userData.hoverEmissive != null ? mesh.userData.hoverEmissive : 0xb86a00;
    mesh.material.emissive.setHex(hov);
    mesh.material.emissiveIntensity = 0.4 + k * 0.9;
  }
}
```
